# Contributing to Open Source Kigali

Welcome! 🎉 Thank you for wanting to contribute to Open Source Kigali. We encourage contributions from everyone — students, developers, startups, and tech communities.

This guide will help you **submit your open source project** or **contribute to existing projects** in our community.

---

## 1. How to Contribute to Existing Projects

1. Browse projects in **`PROJECTS.md`**.
2. Pick a project you want to contribute to.
3. Fork the project repository to your account.
4. Make your changes in a new branch.
5. Submit a Pull Request (PR) to the original repository.

**Tips:**

- Look for issues labeled `good first issue` if you're new.
- Follow any coding style or contribution guidelines of the project.
- Be respectful and collaborative.

---

## 2. How to Add a New Project

We accept new project submissions in two ways:

### Option 1: Fork & Pull Request (Recommended)

1. Fork the `about-open_source_kigali` repository.
2. Open `PROJECTS.md`.
3. Add your project under the correct category using this format:

```markdown
- **Project Name**  
  Short description (1–2 lines)  
  **Tech:** technologies used  
  **Repo:** GitHub repository link  
  **Maintainer:** @github-username
```

4. Commit your changes.
5. Open a Pull Request (PR) with a clear title.
6. Admins will review and merge your PR.

### Option 2: Create an Issue (Beginner-Friendly)

1. Go to **Issues** → **New Issue**.
2. Choose the **Project Proposal template**.
3. Fill in the project details.
4. A maintainer will review and add your project.

---

## 3. Contribution Rules

- Projects **must be open source**.
- Repository must be **public**.
- The project repository must include a **README**.
- Respect community guidelines and other contributors.

---

- **HealthTech** – Healthcare & medical solutions
- **GovTech** – Public services & civic tech
- **Cloud & DevOps**
- **AI & Data**
- **Open Tools / Libraries**
